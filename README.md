## About  
This project provides an end-to-end pipeline for human pose estimation using deep learning. It includes data preparation, model training, evaluation, and inference for detecting human body keypoints in images/videos.

## Features  
- Preprocessing and augmentation pipeline for pose estimation data  
- Deep learning model (or models) for 2D human keypoint detection  
- Training and testing notebooks/scripts  
- Inference script to detect poses in new images or video  
- Visual outputs (pose skeleton overlays) for results
